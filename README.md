## What Is Rez Proxy?

Rez Proxy is a RESTful API service that provides remote access to Rez package management functionality. It allows you to interact with Rez repositories, resolve package dependencies, and manage environments through HTTP endpoints.

This project aims to make Rez functionality accessible to web applications, CI/CD pipelines, and other services that need to interact with Rez programmatically.

## Features

* RESTful API for Rez package management
* Package resolution and dependency management
* Environment configuration through HTTP endpoints
* Cross-platform support (Linux, OSX, Windows)
* FastAPI-based implementation with automatic documentation
* Configurable Rez settings and repositories
